棒グラフ・ヒストグラム

今日の目標

  1. ggplot2 の基本的な考え方（レイヤー構造）を理解する。
  2. 棒グラフ（geom_bar() / geom_col()）を描けるようになる。

今回から ggplot2 を本格的に使っていきます。

3.2 ggplot2 の基礎

ggplot2 とは

ggplot2 は、Hadley Wickham が開発した R のグラフ作成パッケージです。 「Grammar of Graphics（グラフィックスの文法）」 という考え方に基づいており、 グラフを「部品の組み合わせ」として構築します。

R でグラフを描く主な方法を比較すると次のとおりです。

方法 関数の例 特徴
Base R plot(), hist(), barplot() R 標準搭載。手軽だが細かい調整が難しい
ggplot2 ggplot() + geom_*() レイヤーを重ねる。美しく・柔軟・再現しやすい

この講義では ggplot2 を一貫して使います。

レイヤー構造

ggplot2 の最大の特徴は、グラフを レイヤー（層） として積み重ねる点です。

ggplot(data = データ, aes(x = X軸変数, y = Y軸変数))  # キャンバスの準備
  + geom_bar()          # 棒グラフのレイヤー
  + labs(title = "...")  # タイトルのレイヤー
  + theme_minimal()      # テーマのレイヤー

+ でどんどんレイヤーを足していくイメージです。 レゴブロックを積み上げるように、後から何でも追加・変更できます。

覚えるべき基本の 3 点セット

  1. ggplot(data = データ, aes(...)) ： キャンバスを用意する。データにはグラフを描くデータを入れる、aes() に変数を入れる。

  2. geom_*() ─： 図形を描く。geom_bar(), geom_histogram() など

    geom は Geometric object（ジオメトリック・オブジェクト） の略です。
    日本語に直すと 「幾何学的オブジェクト」 となります。
    グラフを描くとき、データ（点や数値）そのものはただの数字の集まりですが、それを「点」で見せるのか、「棒」で見せるのか、「線」で見せるのかという 「図形的な形」 を指定するのが geom_* の役割です

  3. + ─： レイヤーをつなぐ演算子。|> パイプとは別物！

aes()の主な引数

aes() の中で、変数とグラフの見た目を対応させます（= マッピング）。

aes は Aesthetics（エステティクス）の略です。日本語に訳すと「美学」や「美意識」といった意味になりますが、データ分析の文脈（特に ggplot2 パッケージ）では「視覚的属性」と理解するのが一番しっくりきます。

引数 役割 例
x X 軸に使う変数 x = class
y Y 軸に使う変数 y = hwy
fill 塗りつぶしの色に使う変数（棒・箱など） fill = drv
color 輪郭線の色に使う変数 color = class
size 点や線の大きさ size = displ

fill と color の違い

棒グラフのような「面積」を持つ図形では、 fill（塗りつぶし）と color（輪郭）は別々に設定できます。 点・線だけの図形（散布図など）では主に color を使います。

3.4 棒グラフ

棒グラフとヒストグラムの違い

見た目はよく似ていますが、用途がまったく異なります。

棒グラフ（Bar chart） ヒストグラム（Histogram）
対象変数 離散変数（カテゴリ・整数） 連続変数（実数）
棒と棒の間 隙間がある 隙間なし
関数 geom_bar() / geom_col() geom_histogram()
例 車のクラス別台数 ダイヤモンドの価格分布
Note

離散変数 vs 連続変数

  • 離散変数：「compact」「SUV」や「4」「6」のように、決まった値しかとらない変数
  • 連続変数：「15,432 ドル」のように、理論的にどんな値もとりうる変数

棒グラフは「カテゴリごとの個数・合計」を示すのに最適です。

geom_bar() の基本

geom_bar() は、指定した変数の値の個数を自動で数えて棒グラフにします。 y は指定不要です。

ggplot(data = mpg, aes(x = class)) +
  geom_bar()

aes(x = class) と書くだけで、種類ごとの行数（台数）を数えて棒にしてくれます。

Note

geom_bar() の stat（統計変換）

geom_bar() はデフォルトで stat = "count" が設定されており、 自動的に個数を数えます。このため y の指定が不要です。

すでに「個数」「合計」などの値がデータにある場合は、 後述の geom_col() を使います。

色を変える

fill で塗りつぶしの色を変える

ggplot(data = mpg, aes(x = class)) +
  geom_bar(fill = "steelblue")
1
aes() の外に書くと、全棒を同じ色にする 
ggplot(data = mpg, aes(x = class, fill = class)) +
  geom_bar()
1
aes() の中に fill = 変数 を書くと、カテゴリごとに色が変わる

color（輪郭色）と組み合わせる

ggplot(data = mpg, aes(x = class)) +
  geom_bar(fill = "steelblue", color = "white", linewidth = 0.5)
1
color が輪郭の色、linewidth が輪郭の太さ

軸ラベル・タイトルを追加する

labs() レイヤーでタイトルや軸ラベルを設定します。

ggplot(data = mpg, aes(x = class)) +
  geom_bar(fill = "steelblue", color = "white") +
  labs(
    title = "車のクラス別台数",
    x = "種類",
    y = "台数",
    caption = "データ出典: mpg (ggplot2)"
  )
1
グラフのタイトル
2
X 軸のラベル
3
Y 軸のラベル
4
キャプション（右下に表示）

棒を並べ替える

デフォルトでは棒がアルファベット順に並びます。 個数が多い順に並べると読みやすくなります。

fct_infreq() で頻度順に並べる

ggplot(data = mpg, aes(x = fct_infreq(class))) +
  geom_bar(fill = "steelblue", color = "white") +
  labs(
    title = "車のクラス別台数（頻度順）",
    x = "クラス",
    y = "台数"
  )
1
fct_infreq() で因子の順序を頻度の多い順に変換する（forcats パッケージの関数）
Note

forcats パッケージ

因子（カテゴリ変数）の順序を操作するためのパッケージです。 tidyverse に含まれているので、別途インストール不要です。

関数 効果
fct_infreq() 頻度の多い順
fct_rev() 逆順
fct_reorder(変数, 値) 値の大きさで並べ替え

横向き棒グラフ

カテゴリ名が長い場合、横向き（水平）にすると読みやすいです。

ggplot(data = mpg, aes(x = fct_infreq(manufacturer))) +
  geom_bar(fill = "steelblue", color = "white") +
  coord_flip() +
  labs(
    title = "メーカー別台数",
    x = "メーカー",
    y = "台数"
  )
1
メーカー名は長いので横向きにすると読みやすい
2
coord_flip() で X 軸と Y 軸を入れ替える
Note

モダンな書き方

ggplot2 3.3.0 以降は coord_flip() の代わりに、 aes(y = class) のように Y 軸に直接カテゴリを指定する方法も使えます。

ggplot(data = mpg, aes(y = fct_infreq(manufacturer))) +
  geom_bar(fill = "steelblue")

どちらでも同じ結果になります。

グループ別の棒グラフ

fill に別の変数を指定すると、グループ別の棒グラフになります。

積み上げ棒グラフ（デフォルト）

ggplot(data = mpg, aes(x = class, fill = drv)) +
  geom_bar() +
  labs(
    title = "クラス・駆動方式別台数",
    x = "クラス", y = "台数",
    fill = "駆動方式"
  )
1
fill = drv で駆動方式ごとに色分け
2
labs() の fill で凡例のタイトルを設定

並列棒グラフ（position = "dodge"）

ggplot(data = mpg, aes(x = class, fill = drv)) +
  geom_bar(position = "dodge") +
  labs(
    title = "クラス・駆動方式別台数（並列）",
    x = "クラス", y = "台数",
    fill = "駆動方式"
  )
1
position = "dodge" で横に並べる（デフォルトは "stack"）

割合の積み上げ棒グラフ（position = "fill"）

ggplot(data = mpg, aes(x = class, fill = drv)) +
  geom_bar(position = "fill") +
  labs(
    title = "クラス別の駆動方式の割合",
    x = "クラス", y = "割合",
    fill = "駆動方式"
  ) +
  scale_y_continuous(labels = scales::percent)
1
position = "fill" で各棒を 100% に正規化
2
Y 軸をパーセント表示に変換
Note

position 引数まとめ

値 効果
"stack" 積み上げ（デフォルト）
"dodge" 横に並列
"fill" 割合に正規化

geom_col() 値を直接指定する

geom_bar() はデータの個数を自動で数えますが、 データにすでに集計値がある場合は geom_col() を使います。

# まず dplyr でデータを集計する
mpg_avg <- mpg |>
  group_by(manufacturer) |>
  summarise(avg_hwy = mean(hwy)) |>
  arrange(desc(avg_hwy))

# geom_col() で棒グラフを描く
ggplot(data = mpg_avg, aes(x = reorder(manufacturer, avg_hwy), y = avg_hwy)) +
  geom_col(fill = "steelblue", color = "white") +
  coord_flip() +
  labs(
    title = "メーカー別の平均高速道路燃費",
    x = "メーカー",
    y = "平均燃費 (mpg)"
  )
1
降順に並べ替えて集計
2
reorder(manufacturer, avg_hwy) で燃費順にメーカーを並べる
Note

geom_bar() vs geom_col() の使い分け

geom_bar() geom_col()
y の指定 不要（自動でカウント） 必要（値を指定）
典型的な用途 個数を数える 平均・合計などの集計値

テーマを変える

theme_*() でグラフ全体のデザインを変更できます。

ggplot(data = mpg, aes(x = fct_infreq(class))) +
  geom_bar(fill = "steelblue", color = "white") +
  labs(title = "車のクラス別台数", x = "クラス", y = "台数") +
  theme_minimal()
1
theme_minimal() はシンプルで講義資料に向いています
Note

主なテーマ一覧

テーマ 特徴
theme_gray() デフォルト（グレー背景）
theme_bw() 白背景・黒枠
theme_minimal() ミニマル（格子線のみ）
theme_classic() 古典的（枠線のみ）

3.6 ヒストグラム

ヒストグラムは連続変数の分布を確認するための基本的なグラフです。

  • データをビン（bin）と呼ばれる区間に分割する
  • 各ビンに含まれるデータの個数（頻度）を棒の高さで示す
  • 棒の間には隙間がない（← 棒グラフとの違い！）
ggplot(data = diamonds, aes(x = price)) +
  geom_histogram()
`stat_bin()` using `bins = 30`. Pick better value `binwidth`.
Important

「stat_bin() using bins = 30」という警告について

ヒストグラムを描くと、上記のような警告メッセージが表示されます。 これは「ビン数（区間の数）がデフォルトの 30 になっています」という意味です。 警告というより「お知らせ」に近く、エラーではありません。 次のセクションでビン数を自分で設定する方法を学びます。

ビンの幅を調整する

ビンの幅（区間の広さ）の設定は、ヒストグラムで最も重要な調整です。

binwidth（ビンの幅を指定）

# 細かいビン（binwidth = 500 ドル）
ggplot(data = diamonds, aes(x = price)) +
  geom_histogram(binwidth = 500) +
  labs(title = "binwidth = 500", x = "価格（ドル）", y = "個数")

# 粗いビン（binwidth = 2000 ドル）
ggplot(data = diamonds, aes(x = price)) +
  geom_histogram(binwidth = 2000) +
  labs(title = "binwidth = 2000", x = "価格（ドル）", y = "個数")
1
500 ドル刻みで区切る（細かい分布がわかる）
2
2000 ドル刻みで区切る（全体の形がわかる）

ビン幅の比較

Note

bins vs binwidth

引数 意味 いつ使う
bins = 30 ビン数を指定（デフォルト値） データの範囲を知らない場合
binwidth = 500 ビン幅を指定（単位はデータの単位） 意味のある幅を設定したい場合

データの単位がわかる場合は binwidth のほうが直感的です。

色と見た目を整える

ggplot(data = diamonds, aes(x = price)) +
  geom_histogram(
    binwidth = 500,
    fill = "steelblue",
    color = "white",
    linewidth = 0.3
  ) +
  labs(
    title = "ダイヤモンド価格の分布",
    x = "価格（ドル）",
    y = "個数",
    caption = "データ出典: diamonds (ggplot2)"
  ) +
  theme_minimal()
1
棒の塗りつぶし色
2
棒の輪郭色（白にすると境界がわかりやすい）
3
輪郭の太さ

グループ別のヒストグラム

fill 変数で色分け（重ねて表示）

ggplot(data = diamonds, aes(x = price, fill = cut)) +

fill = cut でカット品質ごとに色分け
2

facet_wrap() で分割表示

重ねて表示すると見にくい場合は、分割（ファセット）表示が便利です。

ggplot(data = diamonds, aes(x = price)) +
  geom_histogram(binwidth = 500, fill = "steelblue", color = "white") +
  facet_wrap(~ cut, ncol = 2) +
  labs(
    title = "カット品質別の価格分布",
    x = "価格（ドル）", y = "個数"
  ) +
  theme_minimal()
1
facet_wrap(~ 変数) でパネルに分割。ncol で列数を指定
Note

facet_wrap() の主な引数

引数 意味
~ 変数 どの変数で分割するか
ncol = 2 列数
nrow = 3 行数
scales = "free_x" 各パネルで X 軸の範囲を独立させる

scales = "fixed"（デフォルト）は全パネルで軸の範囲を統一します。 比較したい場合は固定、分布の形だけ見たい場合は "free" が便利です。

軸の表示を整える

数値が大きい場合、X 軸のラベルが見にくくなります。

ggplot(data = diamonds, aes(x = price)) +
  geom_histogram(binwidth = 500, fill = "steelblue", color = "white") +
  scale_x_continuous(
    labels = scales::dollar,
    breaks = seq(0, 20000, by = 5000)
  ) +
  labs(
    title = "ダイヤモンド価格の分布",
    x = "価格", y = "個数"
  ) +
  theme_minimal() +
  theme(axis.text.x = element_text(angle = 45, hjust = 1))
1
scales::dollar でドル表記（コンマ区切り・$マーク）に変換
2
X 軸の目盛りを 0〜20000 ドルの範囲で 5000 刻みに設定
3
X 軸ラベルを 45 度に傾けて重ならないようにする
