15  論文のレプリケーション1

「NHK受信料を払っているのは誰か」を R で再現する

今日の目標

  1. レプリケーション（再現）とは何か、なぜ大切なのかを理解する。
  2. 実際の論文を読み、問い・仮説・データ・分析・考察が論文のどこに書かれているかを確認する。
  3. 論文と同じデータを使い、記述統計・グラフ・重回帰分析（交差項を含む）を R で自力で再現して、同じ結果が出るかを確かめる。
  4. 再現した結果をもとに、分析から何が分かったかを自分の言葉でまとめる。
Note

今日の位置づけ

前回は、学習用に作られたデータで「データ分析の5つのステップ」を体験しました。今日は、実際に大学生が書いた論文を1本取り上げ、論文の中で5つのステップがどう使われているかを読み取りながら、その分析を自分の手で再現します。

次回（第3回）は、別の論文で同じことを行います。

Important

分からないところは、まず論文の該当ページをもう一度読む、前期の講義資料を見返すことから始めましょう。それでも分からないときは、遠慮なく手を挙げて質問してください。生成 AI に質問するのも構いませんが、出てきたコードは自分で理解してから使ってください。

15.1 レプリケーションとは

レプリケーション（replication）とは、すでに発表された研究の分析を、同じデータ・同じ方法でもう一度行い、同じ結果が得られるかを確かめることです。

なぜレプリケーションが大切なのでしょうか。

  • 研究の信頼性を確かめるため：同じデータで同じ分析をしても同じ結果が出ないなら、その研究の結論は信用できません。近年、心理学や経済学などで「有名な研究の結果が再現できない」という問題（再現性の危機）が大きく取り上げられています。
  • 分析の手順を学ぶため：論文には「何をしたか」は書かれていても、「どうやったか（コード）」は書かれていないことが多いです。自分で再現しようとすると、論文の一文一文がどの操作に対応しているのかを考えることになり、分析の力が大きく伸びます。
  • 研究の出発点にするため：再現できたら、変数を加える・データを変えるなど、少し手を加えて自分の分析に発展させることができます。
Important

レプリケーションは「論文のあら探し」ではありません。論文を正確に読み、自分の手で確かめるための練習です。うまく再現できなかったときも、「どこが違うのか」「なぜ違うのか」を考えることに意味があります。

15.2 論文の構成と5つのステップ

実証分析の論文は、多くの場合、次のような構成になっています。これは前回学んだ5つのステップとほぼ対応しています。

論文の章 書かれていること 5つのステップ
はじめに 研究の背景、問い
（何を明らかにしたいか）		 1
先行研究 これまでの研究で分かっていること 1
理論と仮説 問いに対する予想（仮説）と、その理由 1
データ 使ったデータの出典・変数の説明・記述統計・グラフ 2・3
分析結果 回帰分析などの結果とその解釈 4
結論と展望 結果のまとめ、分かったこと、限界と今後の課題 5

後期の総合分析演習のレポートも、この構成を目標にして書きます。今日の論文を、レポートの「お手本」として読んでください。

Note

論文で使われる言葉

論文では「従属変数」「独立変数」という言葉が使われています。前期の回帰分析の言葉では、従属変数＝被説明変数（\(Y\)）、独立変数＝説明変数（\(X\)）です。論文の「コントロール変数」は、主な関心ではないものの、\(Y\) に影響しそうなので一緒にモデルに入れておく説明変数のことです。

15.3 今日の論文とデータ

今日の論文

矢澤翼・永瀬真鈴（2016）「NHK受信料を払っているのは誰か」平成28年度 拓殖大学研究所奨学論文

拓殖大学政経学部の浅野正彦先生のゼミで書かれた論文です。都道府県によって NHK 受信料の支払率に大きな差がある（秋田県 97% に対して沖縄県 46.8%）のはなぜか、を重回帰分析で調べています。

今日のデータ（nhk.csv）

論文の著者が分析に使ったデータです（論文の Appendix に変数の説明があります）。47都道府県が1行ずつ入っています。

変数名 内容 出典
pref 都道府県名（ローマ字）
nhk NHK 受信料の支払率（%） NHK 放送文化研究所（2014年度末）
kosu 賃貸住宅（共同住宅）の戸数（戸） 日本賃貸住宅管理協会
mobility 人口移動率（%）：5年間で住む場所が変わった人の割合 国勢調査（2010年）
ldp 自民党得票率（%）：衆議院選挙の比例区 総務省（2014年）
age 高齢化率（%）：65歳以上の人口の割合 高齢社会白書（2014年）
income 一人当たりの県民所得（千円） 内閣府 県民経済計算
Note

実際の研究で使われたデータは、きれいに整っているとは限りません。分析を始める前に、データの中身をよく確認しましょう（課題3）。

15.4 今日の準備

1. 新規 R プロジェクトを作成する。Directory name は「LessonB02」、場所は Kドライブの「R_programming」。
2. Blackboard から nhk.csv・2016_yazawa_marin.pdf（論文）・assignmentB02.qmd をダウンロードし、「R_programming/LessonB02」フォルダに入れる。
3. まずは氏名（学籍番号）を記入し、この状態で Rendering ができるか確認する。
4. 左側に Rendering して出力された画面を置き、右半分には RStudioを置いて assignmentB02.qmd の課題に取り組む。
5. 適当なところで Rendering し、確かめながら進める。

assignmentB02.qmd には、5つのステップに沿って次の課題が並んでいます。論文の該当ページを読みながら、課題1から順に取り組んでください。

15.7 課題のヒント

課題に取り組んでいて困ったときは、該当する課題のヒントを開いてください。まずは自分の力で考え、どうしても進めないときに開くようにしましょう。

コードのヒントの ___ の部分は、自分で考えて埋めてください。

Note

Render が止まったときは

Render の途中でエラーが出ると、HTML は作られません。Background Jobs（または Render）タブのエラーメッセージに出ているチャンクの名前（label）を確認し、そのチャンクのコードを直してから、もう一度 Render しましょう。課題を1つ終えるごとに Render すると、どこでエラーが出たのかすぐに分かります。

Tip課題1のヒント
  • 論文の p.2 に「本論文の目的は、……」という一文があります。これが問いにあたります。
  • 「なぜ〜なのか」「〜は何によって決まるのか」という疑問文の形に書き直すと、問いとして分かりやすくなります。
  • 表1（p.3）を見ると、支払率が最も高い県と最も低い県で、どのくらい差があるかが分かります。
Tip課題2のヒント
  • 4つの仮説は、p.4〜5 に「仮説1.」〜「仮説4.」として書かれています。
  • 仮説の文の「〜ほど受信料を支払わない」は支払率が下がる（−）、「〜ほど受信料を支払う」は支払率が上がる（＋）という予想です。
  • 仮説4は「自民党の支持が高い県では、人口移動率が高くても受信料を払う」という予想です。人口移動率のマイナスの影響を、自民党得票率が弱める方向に働くとき、交差項の係数の符号はどうなるでしょうか（前期第12回）。
  • コントロール変数は、p.5 の図1の上に「コントロール変数として……を加え」と書かれています。
Tip課題3のヒント
  • データの行数・列数・変数の型は glimpse() で確認できます。
  • 1つの列だけを表示するには データ名$列名 と書きます。
  • 都道府県名の表記を直すには、次の2つの関数を mutate() の中で使います。
    • str_remove(列名, "取り除く文字")：文字列から指定した文字を取り除く
    • str_to_lower(列名)：文字列をすべて小文字にする
# ① データの行数・列数・変数の型を確認する
___(df_nhk)

# ② 都道府県名を表示する
df_nhk$___

# ③ 表記の揺れを直す
df_nhk <- df_nhk |>
  ___(
    pref = str_remove(pref, ___),
    pref = str_to_lower(___)
  )

# ④ 直ったことを確認する
df_nhk$pref
Tip課題4のヒント
  • 表2には、交差項「人口移動率 × 自民党得票率」も載っています。まず mutate() で、2つの列を掛け算した新しい列を作ります。
  • 複数の変数について平均などをまとめて計算するには、pivot_longer() でデータを縦長（「変数名」の列と「値」の列の2列）に変形してから、group_by() と summarise() を使うと便利です。
  • fct_inorder() を使うと、変数の並び順が select() で選んだ順になります（使わないとアルファベット順になります）。
df_nhk |>
  mutate(mob_ldp = ___ * ___) |>                         # 交差項の列を作る
  select(nhk, kosu, mobility, ldp, mob_ldp, age, income) |>
  pivot_longer(everything(), names_to = "variable", values_to = "value") |>
  mutate(variable = fct_inorder(variable)) |>           # 変数の並び順を固定する
  group_by(___) |>
  summarise(
    mean = mean(value),
    sd   = ___(value),
    min  = min(value),
    max  = ___(value),
    .groups = "drop"
  )
Tip課題5のヒント
  • 散布図は geom_point()、回帰直線は geom_smooth(method = "lm", se = FALSE) で描きます（前期第4回）。
  • 点の近くに文字を表示するには geom_text(aes(label = 列名)) を使います。vjust = -0.8 とすると、文字が点の少し上に表示されます。
  • 図4は、図3のコードの x 軸の変数と軸ラベルを変えるだけで描けます。
df_nhk |>
  ggplot(aes(x = ___, y = ___)) +
  geom_point(color = "steelblue") +
  geom_text(aes(label = ___), size = 2.5, vjust = -0.8) +
  geom_smooth(method = "lm", se = FALSE, color = "gray30") +
  labs(x = "人口移動率（%）", y = "受信料支払率（%）") +
  theme_minimal()
Tip課題6のヒント
  • 重回帰分析は lm(被説明変数 ~ 説明変数1 + 説明変数2 + ..., data = データ名) です（前期第10回）。
  • tidy() で係数と p 値を、glance() で補正 R²（adj.r.squared）を確認できます。
  • kosu の係数は -2.83e-06 のように表示されます。これは \(-2.83 \times 10^{-6} = -0.00000283\) のことです。
model1 <- lm(___ ~ kosu + ___ + ___ + age + income, data = df_nhk)

tidy(model1)
glance(model1)
Tip課題7のヒント
  • 交差項は、2つの変数を * でつなぎます。x1 * x2 は x1 + x2 + x1:x2 と同じ意味です（前期第12回）。
  • 2つのモデルを並べて表示するには modelsummary() を使います（前期第10回）。
  • modelsummary() では kosu の係数が小さすぎて 0.000 と表示されます。細かい値は tidy() で確認しましょう。
model2 <- lm(nhk ~ kosu + ___ ___ ___ + age + income, data = df_nhk)

modelsummary(list("表3" = ___, "表4" = ___),
             stars = TRUE, gof_map = c("nobs", "r.squared", "adj.r.squared"))
Tip課題8のヒント
  • 仮説が「支持された」と言えるのは、係数の符号が予想と同じで、かつ p 値 < 0.05 のときです。符号が予想と同じでも、p 値が 0.05 以上なら「支持されない」となります。
  • 仮説1〜3の結果は課題6の model1、仮説4（交差項）の結果は課題7の model2 で確認します。
  • 問いへの答えは、「〜な県ほど、受信料の支払率が高い（低い）」という形で書くと分かりやすくなります。支持されなかった仮説についても、「〜とは関係がなかった」と書きましょう。
  • 仮説4は、「自民党得票率が高い県では、人口移動率が高くても……」のように、2つの変数を組み合わせて書きます。
  • 最後に、自分のまとめと論文の結論（p.13）が同じになっているかを確かめましょう。

15.8 まとめ

項目 ポイント
レプリケーション 同じデータ・同じ方法で分析し、同じ結果が得られるかを確かめる
論文の構成 はじめに・先行研究・仮説 → データ → 分析結果 → 結論（＝5つのステップ）
再現の確かめ方 論文の表・図の数字を、自分の結果と一つひとつ比べる
まとめ 仮説ごとに支持されたかを確かめ、問いに対する答えを自分の言葉で書く
