16  論文のレプリケーション2

「七三分けと得票率の関係」を R で再現する

今日の目標

  1. 候補者一人ひとりのデータを使った論文を読み、問い・仮説・データ・分析・考察が論文のどこに書かれているかを確認する。
  2. ダミー変数（0 と 1 の変数）を含むデータの記述統計・グラフ・重回帰分析を R で自力で再現して、同じ結果が出るかを確かめる。
  3. 分析の結果が仮説と逆になったとき、それをどう読み取り、どう考察すればよいかを考える。
  4. 再現した結果をもとに、分析から何が分かったかを自分の言葉でまとめる。
Note

今日の位置づけ

前回は、都道府県のデータを使った論文「NHK受信料を払っているのは誰か」をレプリケーションしました。今日は、別の論文で同じ5つのステップをもう一度たどります。

前回と違うところは、次の3つです。

  • 分析の単位が都道府県ではなく、選挙に立候補した候補者一人ひとりです。
  • 主な説明変数が「七三分けかどうか」というダミー変数です（前期第11回）。
  • 分析の結果が、論文の仮説と逆になります。
Important

分からないところは、まず論文の該当ページをもう一度読む、前回の課題や前期の講義資料を見返すことから始めましょう。それでも分からないときは、遠慮なく手を挙げて質問してください。生成 AI に質問するのも構いませんが、出てきたコードは自分で理解してから使ってください。

16.1 仮説が支持されないとき

分析をすると、仮説が支持されないことはよくあります。仮説が支持されなかったのは「分析の失敗」ではありません。予想と違う結果も、問いに対する立派な答えです。

ただし、結果を正しく読み取るためには、「支持されない」にも2つの種類があることに注意しましょう。

結果 例（予想は＋） 言えること
有意ではない 係数 ＋0.5（p = 0.40） \(X\) と \(Y\) の間に関係があるとは言えない
予想と逆の符号で有意 係数 −3.0（p = 0.02） \(X\) と \(Y\) の間には関係があるが、その向きが予想と逆

予想と逆の結果が出たときは、考察で次のようなことを考えます。

  • なぜ逆になったのか：仮説の理由づけ（理論）のどこが現実と合わなかったのか。
  • 測り方に問題はないか：変数の作り方やデータの集め方に、結果をゆがめるところはないか。
  • ほかの要因はないか：\(X\) と \(Y\) の両方に影響する別の要因（交絡因子）が隠れていないか。
Note

交絡因子とは

\(X\) と \(Y\) の両方に影響を与える第3の要因のことです。例えば、「七三分けの候補者」と「得票率」の両方に「所属する政党」が影響しているなら、七三分けそのものの効果ではなく、政党の違いを見ているだけかもしれません。重回帰分析でコントロール変数を入れるのは、こうした要因の影響を取り除くためです。

16.2 今日の論文とデータ

今日の論文

石割司悠（2017）「七三分けと得票率の関係」平成29年度 拓殖大学研究所奨学論文

前回と同じく、拓殖大学政経学部の浅野正彦先生のゼミで書かれた論文です。「なぜ男性政治家は皆同じ髪型、特に七三分けをしているのか」という疑問から出発し、2017年7月の東京都議会議員選挙の候補者について、七三分けの候補者ほど得票率が高いのかを重回帰分析で調べています。

今日のデータ（seventhree.csv）

論文の著者が分析に使ったデータです（論文の Appendix に変数の説明があります）。候補者165人が1行ずつ入っています。

変数名 内容
name 候補者の名前（ローマ字、「姓,名」）
seventhree 七三分けダミー：七三分けなら 1、そうでなければ 0
Tfirst 都民ファーストダミー：都民ファーストの会の候補者なら 1、そうでなければ 0
voteshare 得票率（%）：その候補者が選挙区で得た票の割合
age 候補者の年齢（歳）
nocand 候補者数（人）：その候補者が立候補した選挙区の候補者の数
Note

七三分けダミーの作り方

七三分けかどうかは、著者が選挙公報の写真を5人に見せ、5人中3人以上が「七三分けである」と答えた候補者を 1 としています（論文 p.6）。また、女性の候補者と斜めを向いている男性の候補者は判定が難しいため、データから除かれています。データがどのように作られたかは、考察（課題8）で論文の限界を考えるときの手がかりになります。

16.3 今日の準備

1. 新規 R プロジェクトを作成する。Directory name は「LessonB03」、場所は Kドライブの「R_programming」。
2. Blackboard から seventhree.csv・2017_ishiwari.pdf（論文）・assignmentB03.qmd をダウンロードし、「R_programming/LessonB03」フォルダに入れる。
3. まずは氏名（学籍番号）を記入し、この状態で Rendering ができるか確認する。
4. 左側に Rendering して出力された画面を置き、右半分には RStudioを置いて assignmentB03.qmd の課題に取り組む。
5. 適当なところで Rendering し、確かめながら進める。

16.6 課題のヒント

課題に取り組んでいて困ったときは、該当する課題のヒントを開いてください。まずは自分の力で考え、どうしても進めないときに開くようにしましょう。

コードのヒントの ___ の部分は、自分で考えて埋めてください。

Note

Render が止まったときは

Render の途中でエラーが出ると、HTML は作られません。Background Jobs（または Render）タブのエラーメッセージに出ているチャンクの名前（label）を確認し、そのチャンクのコードを直してから、もう一度 Render しましょう。課題を1つ終えるごとに Render すると、どこでエラーが出たのかすぐに分かります。

Tip課題1のヒント
  • Abstract（p.2）と「1. はじめに」（p.3）に「本論文の目的は、……」という一文があります。これが問いにあたります。
  • 「〜ほど〜なのか」「〜は〜に影響するのか」という疑問文の形に書き直すと、問いとして分かりやすくなります。
Tip課題2のヒント
  • 2つの仮説は、p.4〜5 に「仮説1：」「仮説２：」として書かれています。表2・表3（p.9〜10）の「予想」の列も参考になります。
  • 仮説2は「候補者数が少ない選挙区ほど、七三分けの影響が小さい」という予想です。言いかえると、候補者数が多い選挙区ほど、七三分けのプラスの影響が大きくなるということです。このとき、交差項「七三分けダミー × 候補者数」の係数の符号はどうなるでしょうか（前期第12回）。
  • コントロール変数とその予想は、p.5 の図1の上の段落に「その他のコントロール変数として……」と書かれています。
Tip課題3のヒント
  • データの行数・列数・変数の型は glimpse() で確認できます。
  • 欠損値（NA）の数は sum(is.na(データ名)) で数えられます。
  • ある列にどの値が何人いるかは count(列名) で数えられます。

Tip課題4のヒント
  • 前回の課題4と同じように、pivot_longer() でデータを縦長に変形してから、group_by() と summarise() で計算します。
  • name は文字の列なので、平均などは計算できません。select() で5つの変数だけを選んでから変形しましょう。
  • 0 と 1 のダミー変数の平均は、1 の人の割合になります。課題3で数えた人数から、割合を計算して確かめてみましょう。
df_hair |>
  select(seventhree, Tfirst, ___, ___, ___) |>
  pivot_longer(everything(), names_to = "variable", values_to = "value") |>
  mutate(variable = fct_inorder(variable)) |>           # 変数の並び順を固定する
  group_by(___) |>
  summarise(
    mean = ___(value),
    sd   = sd(value),
    min  = min(value),
    max  = max(value),
    .groups = "drop"
  )
Tip課題5のヒント
  • x 軸がダミー変数（0 か 1）なので、そのまま geom_point() で描くと点が縦一列に重なってしまいます。geom_jitter() を使うと、点を少しずつ横にずらして描けます。width = 0.03 で横のずれの幅を、height = 0 で縦にはずらさないことを指定します。
  • 回帰直線は geom_smooth(method = "lm", se = FALSE) で描きます（前期第4回）。
  • グループごとの平均は、group_by() と summarise() で計算できます（前期第6回）。

  geom_smooth(method = "lm", se = FALSE) +
  labs(x = "七三分けダミー", y = "得票率（%）") +
  theme_minimal()

# 七三分けかどうか別の平均得票率と人数
df_hair |>
  group_by(___) |>
  summarise(mean_vote = mean(___), n = n())
Tip課題6のヒント
  • 重回帰分析は lm(被説明変数 ~ 説明変数1 + 説明変数2 + ..., data = データ名) です（前期第10回）。
  • ダミー変数の係数は、「1 のグループが 0 のグループと比べて、平均してどれだけ大きいか（小さいか）」を表します（前期第11回）。
  • 論文の表2では、候補者数の p 値が 2e-16 と書かれています。これは R の summary() が、とても小さな p 値を「< 2e-16」とまとめて表示したものです。tidy() で表示されるもっと小さな値と一致していなくても、再現できていると考えてかまいません。
  • 課題5で計算した平均の差と比べて七三分けダミーの係数が小さくなった理由を考えるときは、「都民ファーストの会の候補者に七三分けは何人いたか」を数えてみましょう。
model1 <- lm(___ ~ seventhree + age + ___ + ___, data = df_hair)

tidy(model1)
glance(model1)

# 都民ファーストかどうか × 七三分けかどうか の人数
df_hair |>
  count(___, ___)
Tip課題7のヒント
  • 交差項は、2つの変数を * でつなぎます。x1 * x2 は x1 + x2 + x1:x2 と同じ意味です（前期第12回）。
  • 2つのモデルを並べて表示するには modelsummary() を使います（前期第10回）。
  • 交差項を入れたモデルでは、七三分けの効果は候補者数によって変わります。

\[ \text{七三分けの効果} = \beta_{\text{七三分け}} + \beta_{\text{交差項}} \times \text{候補者数} \]

  • この式に、候補者数 4 人と 12 人を入れて計算してみましょう。係数は coef(model2) で取り出せます。
model2 <- lm(voteshare ~ ___ ___ ___ + age + Tfirst, data = df_hair)

modelsummary(list("表2" = ___, "表3" = ___),
             stars = TRUE, gof_map = c("nobs", "r.squared", "adj.r.squared"))

# 候補者数が4人の選挙区での七三分けの効果
coef(model2)["seventhree"] + coef(model2)["seventhree:nocand"] * ___
Tip課題8のヒント
  • 仮説が「支持された」と言えるのは、係数の符号が予想と同じで、かつ p 値 < 0.05 のときです。符号が予想と逆で p 値 < 0.05 なら、「支持されない（予想と逆の関係がある）」となります。
  • 仮説1の結果は課題6の model1、仮説2（交差項）の結果は課題7の model2 で確認します。
  • 仮説2は、交差項の符号だけでなく、課題7で計算した「候補者数が4人と12人のときの七三分けの効果」も見て、どちらの選挙区で七三分けの影響が大きかったのかを書きましょう。
  • 考察では、「仮説が支持されないとき」（本資料）の3つの観点と、論文の「6. 結論と今後の展望」（p.11〜12）を参考にしましょう。

16.7 まとめ

項目 ポイント
ダミー変数の記述統計 0 と 1 の変数の平均は、1 の人の割合になる
ダミー変数の係数 1 のグループが 0 のグループと比べて、平均してどれだけ違うか
仮説と逆の結果 「有意でない」と「逆の符号で有意」を区別し、なぜ逆になったのかを考察する
交差項の読み方 係数の符号だけでなく、条件ごとの効果を計算して、文章の解釈と合っているかを確かめる
