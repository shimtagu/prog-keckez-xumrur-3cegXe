17  総合分析演習1

「授業評価と教員」のデータを分析する

今日の目標

  1. 与えられたデータを見て、自分で問いと仮説を立てる。
  2. 「yes / no」で記録された変数を、mutate() と if_else() で 0 と 1 のダミー変数に作り直す。
  3. 記述統計・可視化・単回帰・重回帰を使って、5つのステップのレポートを一人で完成させる。
  4. 次回、自分のレポートの内容（Rコード含む）を自分の言葉で説明できるように準備する。
Note

今日の位置づけ

第2回・第3回は、論文に書かれた問い・仮説・分析をなぞって、同じ結果が出るかを確かめました（レプリケーション）。今日からの総合分析演習では、データだけが与えられます。

  • 問いと仮説は、自分で考えて立てます。
  • 分析の進め方は、これまでと同じ5つのステップです。
  • 総合分析演習は、2回で1セットです。今日（第4回）に分析してレポートを書き、次回（第5回）にその内容を説明します。

17.1 総合分析演習の進め方

総合分析演習は、後期に5回あります。毎回、次の流れで進めます。

回 授業ですること 授業のあとにすること
第4回（今日） データを読み、問いと仮説を立て、assignmentB04.qmd で分析してレポートを書く レポートを仕上げて提出する
第5回（次回） レポートの内容を、教員に一人ずつ説明する（約5分） 振り返りの課題を提出する
Important

提出期限

レポート（assignmentB04.qmd を Render した HTML の ZIP）の提出期限は、次回の授業開始（10月26日 15:45）までです。これ以降は提出できず、レポートを提出していないと次回の説明もできません。

評価：総合分析演習1回分（15%）は、提出したレポートと、次回の説明の内容をあわせて評価します。説明のときに使うチェックシート（5つのステップ × 3段階＝15点）は、第5回の資料に載せています。

17.2 自分で問いを立てる

被説明変数と説明変数を決める

問いは、「何が（説明変数 \(X\)）、何に（被説明変数 \(Y\)）影響するのか」を決めると立てやすくなります。今日のデータでは、被説明変数は授業評価（eval）に決まっています。皆さんが決めるのは、

  1. 授業評価に影響しそうな主な説明変数 \(X\) を1つ
  2. \(X\) と授業評価の両方に影響しそうなコントロール変数を2〜3個

です。

問いは、次のような形で書くと分かりやすくなります。

  • 「\(X\) が大きい（高い）授業ほど、授業評価は高いのか」（\(X\) が数値のとき）
  • 「\(X\) である授業は、そうでない授業と比べて、授業評価が高いのか」（\(X\) がダミー変数のとき）

第1回で確認した良い問いの3つの条件（具体的な変数を指定できている／データで答えられる／比較・関係の視点が入っている）を満たしているか、確かめましょう。

仮説には「理由」をつける

仮説は、「\(X\) が大きいほど \(Y\) は高い（＋）／低い（−）」という予想される符号と、そう予想する理由の2つをセットで書きます。第2回・第3回の論文でも、仮説ごとに理由が書かれていました。

コントロール変数も、同じように予想される符号と理由を書きます。

コントロール変数を選ぶ

第3回の七三分けの論文では、七三分けの候補者は都民ファーストの会に少なく、都民ファーストの候補者は得票率が高かったため、単純に平均を比べると七三分けの影響を大きく見誤ってしまうことを学びました（交絡因子）。

コントロール変数は、主な説明変数 \(X\) と授業評価の両方に関係していそうな変数から選びます。「\(X\) が違う授業は、ほかの点でも違っていないか？」と考えてみましょう。

17.3 今日のデータ

アメリカのテキサス大学オースティン校で、2000〜2002年度に開講された授業の授業評価アンケートの結果です。

今日のデータ（TeachingRatings.csv）

1行が1つの授業です。463の授業が入っています。

変数名 内容
rownames 行の番号（分析には使わない）
minority 担当教員が人種・民族的マイノリティ（白人以外）か：yes / no
age 担当教員の年齢（歳）
gender 担当教員の性別：female（女性）/ male（男性）
credits 1単位の授業か：single（1単位の授業）/ more（それ以外）
beauty 担当教員の見た目の評価（平均が0になるように標準化した値。大きいほど評価が高い）
eval 授業評価：授業全体の評価の平均点（1＝とても不満 〜 5＝とても良い）
division 授業のレベル：upper（3・4年生向けの専門科目）/ lower（1・2年生向けの科目）
native 担当教員の母語が英語か：yes / no
tenure 担当教員がテニュア（終身在職権）を持つ、またはその候補か：yes / no
students 授業評価アンケートに回答した学生の数（人）
allstudents その授業の履修者数（人）
prof 担当教員の番号（1〜94）
Note

見た目の評価（beauty）の作り方

このデータでは、6人の学生（女性3人・男性3人）に教員の写真を見せ、それぞれ見た目を1〜10点で評価してもらいました。その点数を、平均が0、標準偏差が1になるようにそろえて（前期第6回の z スコア）、6人分を平均したものが beauty です。そのため、beauty が 0 なら平均的、プラスなら平均より評価が高い、マイナスなら平均より低いと読みます。

Note

1行は「教員」ではなく「授業」

教員は94人ですが、1人の教員が複数の授業を担当しているため、データは463行あります（prof が同じ行は同じ教員の授業です）。そのため、beauty・age・gender などの教員の情報は、同じ教員の行ではすべて同じ値になっています。

17.6 yes / no の変数をダミー変数にする

今日のデータでは、gender や native などが "female" や "yes" のような文字で記録されています。第3回の七三分けダミーのように、0 と 1 のダミー変数に作り直しておくと、

  • 平均が「1 の授業の割合」になり、記述統計で比べやすい
  • 回帰分析の係数を「1 のグループが 0 のグループと比べて、平均してどれだけ違うか」と読みやすい

という良いところがあります。

ダミー変数は、mutate() の中で if_else(条件, 条件に合うときの値, 合わないときの値) を使って作ります。下の例は、架空の果物のデータで「赤いかどうか」のダミー変数 red を作っています。

library(tidyverse)

df_fruit <- tibble(
  fruit = c("りんご", "バナナ", "いちご", "メロン"),
  color = c("red", "yellow", "red", "green")
)

df_fruit |>
  mutate(red = if_else(color == "red", 1, 0))
1
color が "red" なら 1、そうでなければ 0 を入れた新しい列 red を作る。== はイコールが2つです。 
# A tibble: 4 × 3
  fruit  color    red
  <chr>  <chr>  <dbl>
1 りんご red        1
2 バナナ yellow     0
3 いちご red        1
4 メロン green      0
Important

ダミー変数を作ったら、count() で元の変数と作ったダミー変数の人数（件数）が合っているかを必ず確かめましょう。count() の中に、元の変数と作ったダミー変数をカンマで区切って2つ入れると、その組み合わせごとに件数を数えてくれます。

df_fruit |>
  mutate(red = if_else(color == "red", 1, 0)) |>
  count(color, red)
1
color と red の組み合わせごとに件数を数える。 
# A tibble: 3 × 3
  color    red     n
  <chr>  <dbl> <int>
1 green      0     1
2 red        1     2
3 yellow     0     1

color が red の行だけ red が 1 になっていて（2件）、green と yellow の行は 0 になっていれば正しく作れています。

"red" を "Red" と書くなど、文字を1つ間違えるだけで、すべて 0 になってしまいます。そのときは、count() の結果で red の列が全部 0 になるので、すぐに気づけます。

17.7 本日の課題

assignmentB04.qmd には、5つのステップに沿って次の課題が並んでいます。この課題を全部埋めたものが、総合分析演習1のレポートになります。

ステップ 課題 内容
1 課題1 主な説明変数を選び、問いを立てる
1 課題2 仮説と、コントロール変数（2〜3個）の予想を書く
2 課題3 データを確認し、前処理（ダミー変数の作成）をする
3 課題4 記述統計を計算する
3 課題5 問いに合ったグラフを描く
4 課題6 単回帰分析と重回帰分析を行う
5 課題7 分析の結果、何が分かったかをまとめる

提出方法：Render して出力された HTML ファイルを ZIP 形式に圧縮して Blackboard から提出してください。提出期限は次回の授業開始（10月26日 15:45）までです。

Important

次回は、提出したレポートを画面に映しながら、一人ずつ内容を説明してもらいます。「このコードは何をしているか」「この係数はどういう意味か」と質問されても答えられるように、自分で理解したコードだけを書きましょう。分からないところは、遠慮なく手を挙げて質問してください。生成 AI に質問するのも構いませんが、出てきたコードは自分で理解してから使ってください。

17.8 課題のヒント

課題に取り組んでいて困ったときは、該当する課題のヒントを開いてください。まずは自分の力で考え、どうしても進めないときに開くようにしましょう。

Note

Render が止まったときは

Render の途中でエラーが出ると、HTML は作られません。Background Jobs（または Render）タブのエラーメッセージに出ているチャンクの名前（label）を確認し、そのチャンクのコードを直してから、もう一度 Render しましょう。課題を1つ終えるごとに Render すると、どこでエラーが出たのかすぐに分かります。

Tip課題1のヒント
  • まず「今日のデータ」の変数の表を見て、授業評価（eval）に影響しそうな変数を探しましょう。
  • 主な説明変数は、beauty（見た目）、gender（性別）、age（年齢）、native（英語が母語か）、minority（マイノリティか）、tenure（テニュアか）、credits（1単位の授業か）、division（授業のレベル）などから選べます。
  • rownames・prof は番号なので、説明変数にはしません。
Tip課題2のヒント
  • 仮説は「\(X\) が〜な授業ほど、授業評価が高い（低い）」という形で、予想される符号（＋ か −）とその理由を書きます。
  • コントロール変数は、「主な説明変数が違う授業は、ほかの点でも違っていないか？」と考えて選びます。
  • 理由は、自分が学生として授業評価アンケートに答えるときのことを思い出して考えてみましょう。
Tip課題7のヒント
  • 仮説が「支持された」と言えるのは、係数の符号が予想と同じで、かつ p 値 < 0.05 のときです（第3回）。
  • 問いへの答えは、「〜な授業ほど、授業評価が〜。その差（影響）は、〜をコントロールしても残る（残らない）」のように、係数の大きさも入れて書きます。

17.9 まとめ

項目 ポイント
問いの立て方 被説明変数 \(Y\) と主な説明変数 \(X\) を決め、「\(X\) が〜ほど \(Y\) は〜か」の形で書く
仮説 予想される符号（＋／−）と、その理由をセットで書く
コントロール変数 \(X\) と \(Y\) の両方に関係していそうな変数（交絡因子の候補）を選ぶ

単回帰と重回帰 コントロール変数を入れると、主な説明変数の係数がどう変わるかを比べる
