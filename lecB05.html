18  発表・分析結果説明1

「授業評価と教員」の分析結果を自分の言葉で説明する

今日の目標

  1. 前回のレポートの内容を、5つのステップに沿って自分の言葉で説明する。
  2. 自分の書いたコードが何をしているか、係数や p 値が何を意味するかを説明できるようにする。
  3. 発展課題として、見た目の影響が教員の性別によって違うかを交差項で確かめる。
Note

今日の位置づけ

前回（第4回）は、「授業評価と教員」のデータで自分の問いを立て、5つのステップのレポートを書きました。今日は、そのレポートの内容を一人ずつ教員に説明します。総合分析演習1回分（15%）は、提出したレポートと今日の説明をあわせて評価します。

18.1 今日の進め方

1. 最初に、説明のしかたとチェックシートを確認します。
2. 教員が名前を呼んだ人から順に、教員の席でレポートを画面に映しながら説明します。説明の最中には教員が質問します。（一人約5分）
3. 説明を待っている人・終わった人は、assignmentB05.qmd の課題に取り組みます。
Important

前回のレポートを提出していない人は、今日の説明ができません。説明では、Blackboard に提出した HTML ファイルを開いて使います。提出したファイルを自分の PC でもすぐに開けるようにしておきましょう。

18.2 説明のしかた

レポートの見出しの順に、5つのステップを1つずつ説明します。それぞれ、次のことを話せるようにしておきましょう。

ステップ 話すこと
1 問い・仮説 何を明らかにしたいか（問い）。主な説明変数を選んだ理由、予想される符号とその理由。コントロール変数を選んだ理由
2 データ・前処理 何のデータか、1行は何を表すか、何行あるか。どんな前処理をしたか（作ったダミー変数は何が 1 か）
3 記述統計・可視化 表やグラフから何が読み取れるか。仮説と合っていそうか
4 分析 主な説明変数の係数・p 値の意味。単回帰と重回帰で係数がどう変わったか
5 考察・結論 問いへの答え（係数の大きさも入れて）。仮説は支持されたか
Note

よく聞かれる質問の例

説明の途中で、次のような質問をします。全部に完璧に答える必要はありませんが、自分のレポートに書いたことは、自分の言葉で説明できるようにしておきましょう。

  • なぜこの説明変数（コントロール変数）を選んだのですか。
  • このチャンクの、この行は何をしていますか。
  • if_else(gender == "female", 1, 0) の 1 と 0 は、それぞれ何を表していますか。
  • この係数 0.13 は、どういう意味ですか。p 値は何を表していますか。
  • R² が小さいのは、どういうことを意味しますか。

18.3 評価のチェックシート

説明は、5つのステップごとに3段階（優・良・可）で評価します。5ステップ × 3点 ＝ 15点満点です。

なお、コードの各行が何をしているかも説明できない場合には、該当のステップの評価をマイナスします。

ステップ 優（3点） 良（2点） 可（1点）
1 問い・仮説 問いに \(Y\) と \(X\) が明確で、仮説の符号と理由、コントロール変数を選んだ理由を説明できる 問いと仮説はあるが、理由の説明が弱い 問いや仮説があいまい、または理由を説明できない
2 データ・前処理 データの出典・1行の単位・行数と、前処理（ダミー変数の作り方と確認）を説明できる データの説明か前処理の説明のどちらかが不十分 データや前処理の内容をほとんど説明できない
3 記述統計・可視化 問いに合った表・グラフを示し、そこから読み取れることを問いと結びつけて説明できる 表・グラフはあるが、読み取りが不十分 表・グラフが問いと合っていない、または読み取りができない
4 分析 係数・p 値・R² の意味を正しく説明できる 結果の読み取りに誤りや不足がある 結果の意味をほとんど説明できない
5 考察・結論 係数の大きさを入れて問いに答え、仮説が支持されたかを正しく判断できる 問いへの答えはあるが、係数の大きさや仮説の判断が不十分 問いに答えていない、または結果と合わない結論になっている

18.5 本日の課題

前回の「LessonB04」フォルダに、Blackboard からダウンロードした assignmentB05.qmd を入れて取り組みます（前回と同じ TeachingRatings.csv を使います）。

課題 内容
課題1 発展：見た目の影響は、教員の性別によって違うか（交差項を含む回帰分析）
課題2 発展：課題1の結果をグラフで確かめる
Note

交差項の復習（前期第12回）

「\(X\) が \(Y\) に与える影響の大きさが、グループによって違うか」を調べるときは、交差項を使います。lm(Y ~ X * D, data = ...) と書くと、\(X\), \(D\), \(X \times D\)（交差項）の3つが説明変数に入ります。

\[ Y = \beta_0 + \beta_1 X + \beta_2 D + \beta_3 (X \times D) \]

\(D\) が 0 と 1 のダミー変数なら、

  • \(D = 0\) のグループの \(X\) の傾き：\(\beta_1\)
  • \(D = 1\) のグループの \(X\) の傾き：\(\beta_1 + \beta_3\)

となります。交差項の係数 \(\beta_3\) は、2つのグループの傾きの差です。

提出方法：Render して出力された HTML ファイルを ZIP 形式に圧縮して Blackboard から提出してください。提出期限は金曜日24時です。

18.6 課題のヒント

課題に取り組んでいて困ったときは、該当する課題のヒントを開いてください。まずは自分の力で考え、どうしても進めないときに開くようにしましょう。

コードのヒントの ___ の部分は、自分で考えて埋めてください。

Tip課題1のヒント
  • 前回と同じように、女性ダミー female と1単位の授業ダミー single を作ってから分析します。
  • 交差項は beauty * female と書きます。* を使うと、beauty・female・beauty:female（交差項）の3つが自動で入ります。
  • 男性（female = 0）の傾きは beauty の係数、女性（female = 1）の傾きは beauty の係数＋beauty:female の係数です。
model3 <- lm(eval ~ beauty * ___ + age + single, data = df_eval)
tidy(model3)
glance(model3)
