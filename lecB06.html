19  総合分析演習2

「働く人の賃金」のデータを分析する

今日の目標

  1. 与えられたデータを見て、自分で問いと仮説を立てる。
  2. 3つ以上のカテゴリをもつ変数（職業など）を回帰分析に入れ、係数を「基準のカテゴリと比べて」読めるようになる。
  3. 記述統計・可視化・単回帰・重回帰を使って、5つのステップのレポートを一人で完成させる。
  4. 次回、自分のレポートの内容（Rコード含む）を自分の言葉で説明できるように準備する。
Note

今日の位置づけ

総合分析演習の2回目です。進め方は第4回・第5回と同じで、2回で1セットです。今日（第6回）に分析してレポートを書き、次回（第7回）にその内容を説明します。

第4回のデータは「1行が1つの授業」でしたが、今日のデータは「1行が1人の働く人」です。第5回の説明で受けた質問やコメントを思い出しながら取り組みましょう。

Important

提出期限

レポート（assignmentB06.qmd を Render した HTML の ZIP）の提出期限は、次回の授業開始（11月16日 15:45）までです。これ以降は提出できず、レポートを提出していないと次回の説明もできません。

評価：総合分析演習1回分（15%）は、提出したレポートと、次回の説明の内容をあわせて評価します（5つのステップ × 3段階＝15点満点）。

19.2 自分で問いを立てる

今日のデータでは、被説明変数は時給（wage）に決まっています。皆さんが決めるのは、

  1. 時給に影響しそうな主な説明変数 \(X\) を1つ
  2. \(X\) と時給の両方に影響しそうなコントロール変数を2〜3個

です。問いの立て方、仮説に理由をつけること、コントロール変数の選び方は、第4回と同じです。

Important

今日の条件

主な説明変数とコントロール変数のうち、少なくとも1つは、3つ以上のカテゴリをもつ変数（occupation・sector・ethnicity のどれか）を入れてください。使い方は、下の「3つ以上のカテゴリをもつ変数」で説明します。

19.3 今日のデータ

アメリカで1985年5月に行われた人口動態調査（Current Population Survey、CPS）から取り出した、働く人のデータです。CPS は、日本の「労働力調査」にあたる、アメリカ政府の毎月の調査です。

今日のデータ（CPS1985.csv）

1行が1人の働く人です。534人が入っています。

変数名 内容
rownames 行の番号（分析には使わない）
wage 時給（ドル／時間）。1985年当時の金額
education 教育を受けた年数（年）。高校卒業なら 12、大学卒業なら 16
experience 働いた年数の目安（年）。年齢 − 教育年数 − 6 で計算した値
age 年齢（歳）
ethnicity 人種・民族：cauc（白人）/ hispanic（ヒスパニック）/ other（その他）
region 住んでいる地域：south（南部）/ other（それ以外）

occupation 職業：worker（工場・現場の労働者）/ technical（専門職・技術職）/ services（サービス職）/ office（事務職）/ sales（販売職）/ management（管理職）
sector 産業：manufacturing（製造業・鉱業）/ construction（建設業）/ other（それ以外）

Note

1985年のドル

時給は1985年当時のドルの金額です。物価が違うので、今の日本の時給とそのまま比べることはできません。レポートでは「時給が平均して〇ドル高い」のように、ドルのまま書きましょう。

19.4 今日の準備

1. 新規 R プロジェクトを作成する。Directory name は「LessonB06」、場所は Kドライブの「R_programming」。
2. Blackboard から CPS1985.csv・assignmentB06.qmd をダウンロードし、「R_programming/LessonB06」フォルダに入れる。
3. まずは氏名（学籍番号）を記入し、この状態で Rendering ができるか確認する。
4. 左側に Rendering して出力された画面を置き、右半分には RStudio を置いて assignmentB06.qmd でレポートを書く。
5. 適当なところで Rendering し、確かめながら進める。

19.5 パッケージの準備

大学の PC はシャットダウンするたびに初期化されるため、毎回インストールが必要です。

options(repos = c(CRAN = "https://cran.rstudio.com/"))

install.packages("tidyverse")
install.packages("broom")
install.packages("modelsummary")

19.6 3つ以上のカテゴリをもつ変数

第4回では、female / male のように2つの値しかない変数を、if_else() で 0 と 1 のダミー変数に作り直しました。今日のデータの occupation（職業）は、6つの値（カテゴリ）をもっています。このような変数は、前期第11回で学んだように、文字のまま lm() に入れると、R が自動でダミー変数を作ってくれます。

下の例は、架空の大学生9人の「1週間の勉強時間」と「部活動」のデータです。部活動 club は、sports（運動部）・culture（文化部）・none（入っていない）の3つのカテゴリをもっています。

library(tidyverse)
library(broom)

df_club <- tibble(
  club  = c("sports", "sports", "sports", "culture", "culture", "culture", "none", "none", "none"),
  hours = c(4, 6, 5, 9, 8, 10, 12, 11, 13)
)

まずはカテゴリごとの件数と平均を見る

3つ以上のカテゴリをもつ変数は、平均や標準偏差を計算しても意味がありません。代わりに、count() でカテゴリごとの件数を、group_by() と summarise() でカテゴリごとの平均を確かめます。

df_club |>
  group_by(club) |>
  summarise(mean_hours = mean(hours), n = n())
1
部活動のカテゴリごとにグループ分けする。
2
グループごとに、勉強時間の平均と人数（n()）を計算する。 
# A tibble: 3 × 3
  club    mean_hours     n
  <chr>        <dbl> <int>
1 culture          9     3
2 none            12     3
3 sports           5     3

回帰分析に入れる

model_club <- lm(hours ~ club, data = df_club)
tidy(model_club)
1
文字の変数 club をそのまま説明変数に入れる。 
# A tibble: 3 × 5
  term        estimate std.error statistic    p.value
  <chr>          <dbl>     <dbl>     <dbl>      <dbl>
1 (Intercept)        9     0.577     15.6  0.00000441
2 clubnone           3     0.816      3.67 0.0104    
3 clubsports        -4     0.816     -4.90 0.00271

結果には clubnone と clubsports の2つの係数が出てきて、culture の係数はありません。R は、アルファベット順で最初のカテゴリ（ここでは culture）を基準のカテゴリにして、残りのカテゴリごとにダミー変数を作るためです。

係数 読み方
(Intercept) 基準のカテゴリ（文化部）の平均：9時間
clubnone 部活に入っていない学生は、文化部と比べて平均して 3時間多い
clubsports 運動部の学生は、文化部と比べて平均して 4時間少ない

上のカテゴリごとの平均（文化部 9、入っていない 12、運動部 5）と見比べると、係数が「基準のカテゴリとの差」になっていることが分かります。

Important

3つ以上のカテゴリをもつ変数の係数は、必ず「基準のカテゴリと比べて」読みます。レポートにも、基準のカテゴリが何かを書きましょう。今日のデータの occupation なら、アルファベット順で最初の management（管理職）が基準のカテゴリになります。

19.7 本日のレポート

今回から、assignmentB06.qmd には5つのステップの見出しと、レポートの条件だけが書かれています。パッケージやデータの読み込みも含めて、何をどの順番で書くかを自分で考えてレポートを完成させましょう。第4回の課題ファイルを見返すと、各ステップで何をしたかを思い出せます。

レポートの条件

  • 被説明変数は時給（wage）。主な説明変数1つと、コントロール変数2〜3個を自分で選ぶ。
  • そのうち少なくとも1つは、3つ以上のカテゴリをもつ変数（occupation・sector・ethnicity）にする。
  • 単回帰分析と重回帰分析を行い、modelsummary で並べて表示する。

提出方法：Render して出力された HTML ファイルを ZIP 形式に圧縮して Blackboard から提出してください。提出期限は次回の授業開始（11月16日 15:45）までです。

Important

次回は、提出したレポートを画面に映しながら、一人ずつ内容を説明してもらいます。「このコードは何をしているか」「この係数はどういう意味か」と質問されても答えられるように、自分で理解したコードだけを書きましょう。分からないところは、遠慮なく手を挙げて質問してください。生成 AI に質問するのも構いませんが、出てきたコードは自分で理解してから使ってください。

19.8 ヒント

レポートを書いていて困ったときは、該当するステップのヒントを開いてください。まずは自分の力で考え、どうしても進めないときに開くようにしましょう。

Note

Render が止まったときは

Render の途中でエラーが出ると、HTML は作られません。Background Jobs（または Render）タブのエラーメッセージに出ているチャンクの名前（label）を確認し、そのチャンクのコードを直してから、もう一度 Render しましょう。ステップを1つ終えるごとに Render すると、どこでエラーが出たのかすぐに分かります。

Tipステップ1のヒント（問い）
  • まず「今日のデータ」の変数の表を見て、時給（wage）に影響しそうな変数を探しましょう。
  • rownames は番号なので、説明変数にはしません。
  • experience は年齢と教育年数から計算した値なので、age・education・experience の3つを同時に説明変数に入れるのは避けましょう。
Tipステップ1のヒント（仮説とコントロール変数）
  • 仮説は「\(X\) が〜な人ほど、時給が高い（低い）」という形で、予想される符号（＋ か −）とその理由を書きます。3つ以上のカテゴリをもつ変数なら、「基準のカテゴリと比べて、どのカテゴリの時給が高い（低い）と予想するか」を書きます。
  • コントロール変数は、「主な説明変数が違う人は、ほかの点でも違っていないか？」と考えて選びます。
  • 理由は、アルバイト先や、将来の就職先の給料がどう決まるかを想像して考えてみましょう。
Tipステップ5のヒント
  • 仮説が「支持された」と言えるのは、係数の符号が予想と同じで、かつ p 値 < 0.05 のときです（第3回）。
  • 問いへの答えは、「〜な人ほど、時給が〜。その差（影響）は、〜をコントロールしても残る（残らない）」のように、係数の大きさ（ドル）も入れて書きます。

項目 ポイント
