箱ひげ図・散布図・折れ線グラフ

今日の目標

  1. 箱ひげ図（geom_boxplot()）を描けるようになる。
  2. 散布図（geom_point()）を描けるようになる。
  3. 折れ線グラフ（geom_line()）を描けるようになる。

4.1 パッケージの準備

大学のPCはシャットダウンする度に初期化されるため、毎回インストールが必要です。 毎回授業開始時にこのブロックを実行してください。

install.packages("tidyverse")
install.packages("readxl")
install.packages("gapminder")

必要なパッケージを読み込みます。 折れ線グラフの演習では gapminder パッケージを使います。

library(tidyverse)
library(readxl)
library(gapminder)
Note

gapminder パッケージとは

世界各国の経済・健康データをまとめたデータセットです。

変数名 内容 型
country 国名 文字列（離散）
continent 大陸名 文字列（離散）
year 年（1952〜2007、5年刻み） 数値（離散）
lifeExp 平均寿命（年） 数値（連続）
pop 人口 数値（連続）
gdpPercap 一人当たり GDP（ドル） 数値（連続）

4.3 箱ひげ図

箱ひげ図とは

箱ひげ図（boxplot）は連続変数の分布を視覚的に要約する方法です。 特定のグループごとに「分布の形」を比較するのが得意です。

参考：
なるほど統計学園（総務省）

箱ひげ図の見方（統計WEB）

箱ひげ図で読める情報

要素 意味
箱の下辺（第1四分位数 Q1） データの下位25%の境界
箱の中央線（第2四分位数 Q2 = 中央値） データの真ん中の値
箱の上辺（第3四分位数 Q3） データの上位25%の境界
ひげの上端 Q3 + 1.5 × IQR（四分位範囲）以内の最大値
ひげの下端 Q1 − 1.5 × IQR 以内の最小値
点（●） 外れ値（ひげの外側にある観測値）
Note

ヒストグラム vs 箱ひげ図

ヒストグラム 箱ひげ図
得意なこと 分布の「形」（山の位置・歪み）を把握 複数グループの分布を1つのグラフで比較
グループ比較 facet_wrap() で分割が必要 1つのグラフ内でグループを並べられる
記述統計 直接は読めない 中央値・四分位数がひと目でわかる

geom_boxplot() の基本

geom_boxplot() は x にカテゴリ変数、y に連続変数を指定します。

ggplot(data = mpg, aes(x = class, y = hwy)) +
  geom_boxplot()

ラベルを整える

ggplot(data = mpg, aes(x = class, y = hwy)) +
  geom_boxplot() +
  labs(
    title = "車のクラス別の高速道路燃費",
    x = "クラス",
    y = "高速道路燃費（mpg）"
  ) +
  theme_minimal()

色を変える

fill で箱の塗りつぶし色を変える

ggplot(data = mpg, aes(x = class, y = hwy)) +
  geom_boxplot(fill = "steelblue", color = "gray30") +
  labs(title = "クラス別の高速道路燃費", x = "クラス", y = "燃費（mpg）") +
  theme_minimal()
1
fill で箱の色、color でひげ・輪郭の色を指定

fill に変数をマッピングしてカテゴリごとに色を変える

ggplot(data = mpg, aes(x = class, y = hwy, fill = class)) +
  geom_boxplot() +
  labs(
    title = "クラス別の高速道路燃費",
    x = "クラス", y = "燃費（mpg）",
    fill = "クラス"
  ) +
  theme_minimal()
1
aes() の中に fill = class を書くと、クラスごとに自動的に色が変わる

グループ別の箱ひげ図

x に一つのカテゴリ変数、fill に別のカテゴリ変数を指定すると、 グループ別に色分けした箱ひげ図が描けます。

ggplot(data = mpg, aes(x = class, y = hwy, fill = drv)) +
  geom_boxplot() +
  labs(
    title = "クラス・駆動方式別の高速道路燃費",
    x = "クラス", y = "燃費（mpg）",
    fill = "駆動方式"
  ) +
  theme_minimal()
1
fill = drv で駆動方式ごとに色分け。箱が自動的にグループ別に並ぶ

横向き箱ひげ図

カテゴリ名が長い場合や箱を見やすくしたい場合は、coord_flip() で横向きにします。

ggplot(data = mpg, aes(x = reorder(class, hwy, median), y = hwy, fill = class)) +
  geom_boxplot() +
  coord_flip() +
  labs(
    title = "クラス別の高速道路燃費（中央値順）",
    x = "クラス", y = "燃費（mpg）"
  ) +
  theme_minimal() +
  theme(legend.position = "none")
1
reorder(class, hwy, median) で中央値の大きさ順にクラスを並べ替える
2
coord_flip() で X 軸と Y 軸を入れ替える
3
軸ラベルと凡例の情報が重複するので凡例を非表示にする
Note

reorder() 関数

reorder(並べたい変数, 基準にする変数, 集計関数) の形で使います。

reorder(class, hwy, median)   # hwy の中央値順に class を並べる
reorder(class, hwy, mean)     # hwy の平均値順に class を並べる

coord_flip() との組み合わせで「値の大きい順に上から並ぶ」見やすいグラフになります。

透過率と外れ値

alpha で透過率を設定する

ggplot(data = mpg, aes(x = class, y = hwy, fill = class)) +
  geom_boxplot(alpha = 0.7,
               outlier.color = "red",
               outlier.size = 2) +
  labs(
    title = "クラス別の高速道路燃費",
    x = "クラス", y = "燃費（mpg）"
  ) +
  theme_minimal() +
  theme(legend.position = "none")
1
alpha = 0.7 で透過率 70%（1 = 不透明、0 = 完全透明）
2
outlier.color で外れ値の点の色を変える
3
outlier.size で外れ値の点の大きさを変える

ファセット分割

facet_wrap() で変数ごとにパネルを分割できます。

ggplot(data = mpg, aes(x = class, y = hwy, fill = class)) +
  geom_boxplot(alpha = 0.7) +
  facet_wrap(~ cyl) +
  labs(
    title = "シリンダー数・クラス別の高速道路燃費",
    x = "クラス", y = "燃費（mpg）"
  ) +
  theme_minimal() +
  theme(
    legend.position = "none",
    axis.text.x = element_text(angle = 45, hjust = 1)
  )
1
facet_wrap(~ cyl) でシリンダー数別にパネル分割
2
X 軸ラベルを 45 度傾けて重ならないようにする

4.4 散布図

散布図とは

散布図（scatter plot）は 2 つの連続変数の間の関係（相関）を視覚的に確認するグラフです。 各データ点が 2 次元平面上の点として描かれます。

幾何オブジェクト 意味
ggplot() 図を描くキャンバスを用意する
geom_point() 散布図を描く
Note

因果関係と相関関係

散布図を描く際、X 軸と Y 軸の変数の設定が重要です。

  • 原因と考えられる変数 → X 軸（例：エンジン排気量）
  • 結果と考えられる変数 → Y 軸（例：燃費）

ただし、散布図で見えるのは「相関関係」であり、「因果関係」ではありません。 2 つの変数に強い相関があっても、必ずしも一方が他方の原因とは限りません。

geom_point() の基本

geom_point() は x と y の両方に連続変数を指定します。

ggplot(data = mpg, aes(x = displ, y = hwy)) +
  geom_point()

aes(x = displ, y = hwy) と書くだけで、各車の排気量と燃費の関係が点で表示されます。

ラベルを整える

ggplot(data = mpg, aes(x = displ, y = hwy)) +
  geom_point() +
  labs(
    title = "排気量と高速道路燃費の関係",
    x = "排気量（リットル）",
    y = "高速道路燃費（mpg）",
    caption = "データ出典: mpg (ggplot2)"
  ) +
  theme_minimal()

色・サイズをマッピングする

aes() の中で変数を色やサイズにマッピングすると、追加の情報を同じグラフで表現できます。

color で色を変数にマッピングする

ggplot(data = mpg, aes(x = displ, y = hwy, color = drv)) +
  geom_point() +
  labs(
    title = "排気量と高速道路燃費の関係",
    x = "排気量（リットル）",
    y = "高速道路燃費（mpg）",
    color = "駆動方式"
  ) +
  theme_minimal()
1
color = drv で駆動方式ごとに点の色が変わる

size でサイズを変数にマッピングする

ggplot(data = mpg, aes(x = displ, y = hwy, color = drv, size = cyl)) +
  geom_point(alpha = 0.6) +
  labs(
    title = "排気量・高速道路燃費・シリンダー数・駆動方式の関係",
    x = "排気量（リットル）",
    y = "高速道路燃費（mpg）",
    color = "駆動方式",
    size = "シリンダー数"
  ) +
  theme_minimal()
1
size = cyl でシリンダー数が大きいほど点が大きくなる
2
点が重なる部分は alpha で透明にすると見やすくなる
Note

color と fill の使い分け（点の場合）

geom_point() の点は「面積」を持たないため、通常は color を使います。

図形 使うもの
点（散布図） color（点の色）
棒・箱（棒グラフ・箱ひげ図） fill（塗りつぶし）と color（輪郭）

重なりを解消する（jitter）

データが重なって見えにくい場合、geom_jitter() で点をランダムにずらすことができます。

ggplot(data = mpg, aes(x = drv, y = hwy)) +
  geom_point() +
  labs(title = "geom_point()", x = "駆動方式", y = "燃費（mpg）") +
  theme_minimal()

ggplot(data = mpg, aes(x = drv, y = hwy)) +
  geom_jitter(width = 0.2, height = 0, alpha = 0.6) +
  labs(title = "geom_jitter()", x = "駆動方式", y = "燃費（mpg）") +
  theme_minimal()
1
width で横方向のずらし幅、height で縦方向のずらし幅を指定

jitter を使って点の重なりを解消

回帰直線を追加する（geom_smooth()）

散布図に回帰直線（トレンドライン）を追加するには geom_smooth() を使います。

ggplot(data = mpg, aes(x = displ, y = hwy)) +
  geom_point(alpha = 0.5) +
  geom_smooth(method = "lm",
              se = TRUE,
              color = "red") +
  labs(
    title = "排気量と高速道路燃費の関係（線形回帰）",
    x = "排気量（リットル）",
    y = "高速道路燃費（mpg）"
  ) +
  theme_minimal()
1
method = "lm" で線形回帰（直線）を使う
2
se = TRUE（デフォルト）で 95% 信頼区間を薄い帯で表示
3
color で直線の色を指定 
`geom_smooth()` using formula = 'y ~ x'

グループごとに回帰直線を追加する

ggplot(data = mpg, aes(x = displ, y = hwy, color = drv)) +
  geom_point(alpha = 0.5) +
  geom_smooth(method = "lm", se = FALSE) +
  labs(
    title = "排気量・燃費の関係（駆動方式別）",
    x = "排気量（リットル）",
    y = "高速道路燃費（mpg）",
    color = "駆動方式"
  ) +
  theme_minimal()
1
aes() で color = drv を設定すると、geom_smooth() もグループ別に適用される
2
se = FALSE で信頼区間の帯を非表示にするとすっきりする 
`geom_smooth()` using formula = 'y ~ x'
Note

geom_smooth() の method 引数

値 手法 用途
"lm" 線形回帰 直線的な関係
"loess" LOESS（局所回帰） デフォルト。曲線的な関係
"glm" 一般化線形モデル ロジスティック回帰など

データ数が少ないときは "loess" でも十分ですが、 「直線的な傾向を見たい」ときは method = "lm" を使うのが一般的です。

ファセット分割

ggplot(data = mpg, aes(x = displ, y = hwy)) +
  geom_point(alpha = 0.5, color = "steelblue") +
  geom_smooth(method = "lm", se = FALSE, color = "red") +
  facet_wrap(~ drv, labeller = labeller(drv = c("4" = "4WD", "f" = "前輪", "r" = "後輪"))) +
  labs(
    title = "排気量と高速道路燃費の関係（駆動方式別）",
    x = "排気量（リットル）",
    y = "高速道路燃費（mpg）"
  ) +
  theme_minimal()
1
labeller でパネルのラベルを変更できる 
`geom_smooth()` using formula = 'y ~ x'

4.5 折れ線グラフ

折れ線グラフとは

折れ線グラフはある変数の時系列的な変化を示す際に使われます。 横軸は時間（年・月・日など）、縦軸は値（人口・気温・株価など）です。

幾何オブジェクト 意味
ggplot() 図を描くキャンバスを用意する
geom_line() 折れ線グラフを描く
Note

折れ線グラフの横軸データについての注意点

  • 横軸上の値はグループ内において 1 回だけ登場する
  • 例）総選挙が実施された年の場合、「1996」はデータでは 1 回だけ登場する
  • 横軸が連続変数でも離散変数でも使えるが、順序付きである必要がある

複数の線を描く場合は、color や group でグループを指定します。

geom_line() の基本（1 カ国）

まず、日本の平均寿命の推移を折れ線グラフで描きます。

gapminder |>
  filter(country == "Japan") |>
  ggplot(aes(x = year, y = lifeExp)) +
  geom_line() +
  labs(
    title = "平均寿命の推移（日本）",
    x = "西暦",
    y = "平均寿命（年）"
  ) +
  theme_minimal()
1
filter() で日本のデータのみ抽出
2
パイプ |> から ggplot() に渡す場合、data = は省略できる

点と線を組み合わせる

折れ線グラフに geom_point() を重ねると、各データ点が強調されます。

gapminder |>
  filter(country == "Japan") |>
  ggplot(aes(x = year, y = lifeExp)) +
  geom_line(color = "steelblue", linewidth = 1) +
  geom_point(color = "steelblue", size = 3) +
  labs(
    title = "平均寿命の推移（日本）",
    x = "西暦",
    y = "平均寿命（年）"
  ) +
  theme_minimal()
1
linewidth で線の太さを指定
2
size で点の大きさを指定

複数のグループを描く

複数の国の推移を 1 つのグラフに描くには、 color または group にグループ変数を指定します。

日本・中国・韓国の平均寿命の比較

# 東アジア3カ国を抽出
east_asia <- gapminder |>
  filter(country %in% c("Japan", "China", "Korea, Rep."))

ggplot(data = east_asia, aes(x = year, y = lifeExp, color = country)) +
  geom_line(linewidth = 1) +
  geom_point(size = 2) +
  labs(
    title = "東アジア3カ国の平均寿命の推移",
    x = "西暦",
    y = "平均寿命（年）",
    color = "国名"
  ) +
  theme_minimal()
1

%in% 演算子

%in% は「複数の値のどれかに一致する」かどうかを確認する演算子です。

# 以下の2つは同じ意味
filter(country == "Japan" | country == "China" | country == "Korea, Rep.")
filter(country %in% c("Japan", "China", "Korea, Rep."))

リストが長くなるほど %in% の方が簡潔に書けます。

Important

group 引数が必要なとき

折れ線グラフで複数グループを描く場合、通常は color = グループ変数 を使えば自動的に線が分かれます。しかし、色分けはせずに線だけグループ別に描きたい場合は group = グループ変数 を明示的に指定する必要があります。

# 色で区別する（color を使う）
aes(x = year, y = lifeExp, color = country)

# 色分けなし（全部同じ色で線だけ分ける）
aes(x = year, y = lifeExp, group = country)

特定の国を強調する

多くの線がある中で特定の国を強調したい場合、 レイヤーを重ねる方法が有効です。

  filter(continent == "Asia")

# 日本のデータを別途抽出
japan <- asia |>
  filter(country == "Japan")

# グラフを描く
ggplot() +
  # 全アジア国の薄い線（背景）
  geom_line(data = asia,
            aes(x = year, y = lifeExp, group = country),
            color = "gray70", alpha = 0.5) +
  # 日本の線（強調）
  geom_line(data = japan,
            aes(x = year, y = lifeExp),
            color = "red", linewidth = 1.5) +
  geom_point(data = japan,
             aes(x = year, y = lifeExp),
             color = "red", size = 3) +
  labs(
    title = "アジア各国の平均寿命の推移（日本を強調）",
    x = "西暦",
    y = "平均寿命（年）"
  ) +
  theme_minimal()
